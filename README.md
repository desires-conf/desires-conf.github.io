# desires-conf.org

The DESIRES conference website, hosted on Cloudflare (via the account of Johannes Kiesel)

## Usage

1. Install [Jekyll](https://jekyllrb.com/docs/) (see the OS-specific [guides](https://jekyllrb.com/docs/installation/#guides) for details).
2. Clone this repository.
3. Install additional dependencies:

    ```shell
    bundle install
    ```

4. Build and host locally:

    ```shell
    bundle exec jekyll serve
    ```
